moonweavte

A Weaviate vector store for moonrag, over Weaviate's REST API. It is a module of its own, so a project that does not use Weaviate does not build it.

moon add moonbitstack/moonweavte

Native only: it opens sockets, so it is built for native and skipped for js and wasm.

01 use

One line, like the other stores

It implements the same VectorStore contract as the in-memory store, so a retriever does not know which store it is reading: 

let store = @moonweavte.WeaviateStore::new("http://127.0.0.1:8080", embedder, dimension=256)
let store : &@moonrag.VectorStore = store

create builds the collection or class the server needs and is safe on every start; the standard cases run against a live Weaviate server in CI.

02 rank

The score is the same cosine

Like SQLite and MySQL, this store reads the vectors back and recomputes the cosine in this process with the same cosine_similarity and the same Filter::matches every other backend uses — so all backends agree on what a match is and how a result ranks, rather than each trusting its server.
